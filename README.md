# Building AI - Advanced Track Solutions

This repository contains Python implementations for the Advanced track of the **Building AI** course. The code originates from foundational mathematical concepts: computational search algorithms, probabilistic modeling, and the algebra underlying neural networks.

## Directory: `advanced/`

### Chapter 1: Search and Optimization
* **`chapter1_E2.py` (Exercise 2)** - Combinatorics & brute-force search (Pineapple route).
* **`chapter1_E3.py` (Exercise 3)** - Hill-climbing algorithm applying local search optimization (Reach the highest summit).
* **`chapter1_E5.py` (Exercise 5)** - Probability calculus for randomized state transitions (Warm-up Temperature).
* **`chapter1_E6.py` (Exercise 6)** - Simulated Annealing model originating from thermodynamics for stochastic global search.

### Chapter 2: Probabilistic Models
* **`chapter2_E1.py` (Exercise 7)** - Expected value calculations for discrete random variables (Flip the coin).
* **`chapter2_E2.py` (Exercise 8)** - Bayes' Theorem implementation for updating posterior probabilities (Fishing in the Nordics).
* **`chapter2_E4.py` (Exercise 10)** - Naive Bayes classifier utilizing conditional probability and feature independence.

### Chapter 3: Machine Learning & Vector Spaces
* **`chapter3_E1.py` (Exercise 11)** - Linear regression modeling (Real estate price predictions).
* **`chapter3_E2.py` (Exercise 12)** - Least squares optimization to minimize residual errors.
* **`chapter3_E3.py` (Exercise 13)** - Multiple linear regression (Predictions with more data).
* **`chapter3_E4.py` (Exercise 14)** - Data splitting and evaluation (Training data vs test data).
* **`chapter3_E5.py` (Exercise 15)** - Euclidean and Manhattan metric computations (Vector distances).
* **`chapter3_E6.py` (Exercise 16)** - k-Nearest Neighbor (k-NN) spatial classification (Nearest neighbor).
* **`chapter3_E7.py` (Exercise 17)** - Matrix conversion from unstructured text (Bag of Words).
* **`chapter3_E8.py` (Exercise 18)** - Weighted term frequency highlighting statistical word significance (TF-IDF).

### Chapter 4: Neural Networks
* **`chapter4_E1.py` (Exercise 20)** - Logistic regression utilizing the sigmoid activation function to establish foundational artificial neuron logic.

## Execution
No complex setup or external dependencies are required for the base implementations. All scripts can be executed directly from the terminal:

```bash
python chapter1_E2.py
```
