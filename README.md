# Building AI - Advanced Track Solutions

This repository contains Python implementations for the Advanced track of the **Building AI** course. The code originates from foundational mathematical concepts: computational search algorithms, probabilistic modeling, and the algebra underlying neural networks.

## Directory: `advanced/`

### Chapter 1: Search and Optimization
* **`chapter1_E2.py`** - Combinatorics & brute-force search for optimal routing.
* **`chapter1_E3.py`** - Hill-climbing algorithm applying local search optimization to iterative variable updates.
* **`chapter1_E5.py`** - Probability calculus for randomized state transitions.
* **`chapter1_E6.py`** - Simulated Annealing model (originating from thermodynamics) for stochastic global search.

### Chapter 2: Probabilistic Models
* **`chapter2_E1.py`** - Expected value calculations for discrete random variables.
* **`chapter2_E2.py`** - Bayes' Theorem implementation for updating posterior probabilities.
* **`chapter2_E4.py`** - Naive Bayes classifier utilizing conditional probability and feature independence.

### Chapter 3: Machine Learning & Vector Spaces
* **`chapter3_E1.py`** - Linear regression modeling for scalar variable correlation.
* **`chapter3_E2.py`** - Least squares optimization to minimize residual errors.
* **`chapter3_E3.py`** - Euclidean and Manhattan metric computations in multidimensional vector space.
* **`chapter3_E4.py`** - k-Nearest Neighbor (k-NN) spatial distance classification.
* **`chapter3_E5.py`** - Bag of Words matrix conversion from unstructured text.
* **`chapter3_E6.py`** - TF-IDF vectorization highlighting statistical word significance.
* **`chapter3_E7.py`** - Text classification integrating vector space models.
* **`chapter3_E8.py`** - Train/test data splitting to evaluate structural generalization.

### Chapter 4: Neural Networks
* **`chapter4_E1.py`** - Logistic regression utilizing the sigmoid activation function to establish foundational artificial neuron logic.

## Execution
No complex setup or external dependencies are required for the base implementations. All scripts can be executed directly from the terminal:

```bash
python chapter1_E2.py
```
